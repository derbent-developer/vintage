# VINTAGE — сайт бутика женской одежды (Дербент)

Одностраничный сайт-визитка. Чистый HTML/CSS/JS, без сборки и без библиотек —
достаточно загрузить папку на любой хостинг.

## Что внутри

```
vintage/
├── index.html              — вся разметка страницы
├── assets/
│   ├── css/style.css       — стили и адаптив
│   ├── js/main.js          — скролл-анимации
│   └── img/                — фотографии
└── README.md
```

## Как открыть

Просто дважды кликнуть по `index.html` — сайт откроется в браузере.

## Сайт онлайн

https://derbent-developer.github.io/vintage/

Репозиторий: https://github.com/derbent-developer/vintage

## Как обновить онлайн-версию

1. Поменять что нужно в файлах этой папки (текст в `index.html`,
   фото в `assets/img/`, цвета в `assets/css/style.css`).
2. Дважды кликнуть по файлу **«Обновить сайт.command»**.
3. Через 1–2 минуты изменения появятся на сайте.
   Если страница выглядит по-старому — обновить с очисткой кэша: `Cmd+Shift+R`.

Сам файл «Обновить сайт.command» на сайт не попадает — он только для локальной работы.

## Секции страницы

1. **Экран-обложка** — фото, название, рейтинг 4,3.
2. **Бегущая строка** с направлениями.
3. **О бутике** — текст проявляется по словам при прокрутке + цифры-счётчики.
4. **Коллекции** — витрина едет вбок, пока страница листается вниз (закреплённая секция).
5. **Лукбук** — образы с параллаксом.
6. **Цитата** из отзыва на затемнённом фото.
7. **Отзывы** — 6 реальных отзывов с Яндекс Карт.
8. **Бутик** — интерьер и витрина.
9. **Контакты** — телефон, адрес, часы, карта, кнопки «Позвонить» и WhatsApp.

## Что и где менять

| Что | Где |
|---|---|
| Телефон | `index.html` — поиск по `538-25-50` (шапка, контакты, подвал, WhatsApp) |
| Адрес и часы | `index.html`, блок `<section class="contact">` |
| Тексты и заголовки | `index.html` — секции подписаны комментариями |
| Отзывы | `index.html`, блок `<div class="rev__grid">` |
| Названия категорий | `index.html`, блок `<section class="pin">` |
| Фотографии | заменить файлы в `assets/img/` с теми же именами |
| Цвета | `assets/css/style.css`, блок `:root` в самом верху |

Размеры фотографий: обложка — вертикальная или квадратная от 1200px по ширине,
карточки коллекций и лукбук — вертикальные (примерно 3:4).

## Технические заметки

- Шрифты (Cormorant Garamond и Manrope) подключаются с Google Fonts.
  Без интернета сайт всё равно откроется — подставятся системные шрифты.
- Карта — виджет Яндекс Карт в `<iframe>`. Если виджет не загрузился,
  на его месте видна подпись с адресом.
- Анимации автоматически отключаются, если в системе включён режим
  «уменьшение движения» (prefers-reduced-motion).
- Плавная прокрутка работает на компьютерах; на телефонах используется
  обычная системная прокрутка.

## Перед публикацией стоит проверить

- Фотографии взяты из карточки магазина на Яндекс Картах. Часть снимков там
  загружают сами посетители, поэтому перед публикацией лучше подтвердить с
  владельцем, что все кадры — их и их можно использовать. Идеальный вариант —
  заменить на собственную съёмку (файлы в `assets/img/`).
- Тексты «о бутике» написаны как рекламные, их стоит согласовать с владельцем.
